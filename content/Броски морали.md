# Morale check
Монстры, и нпс, включая союзников имеют параметр морали от 2 до 12, зависящий от них.
Когда Что-то ощутимо идет "не так", например:

| Момент                        |
| ----------------------------- |
| Leader falls                  |
| Heavy losses                  |
| Facing overwhelming force     |
| surprised or badly outmatched |

| Бросок           | Результат                                                 |
| ---------------- | --------------------------------------------------------- |
| 2d6 <= Morale    | Монстр продолжает бой                                     |
| 2d6 **>** Morale | Монстр ломается: бежит, сдаётся, отступает, просит пощады |
- Если прошел проверку дважды то в большинстве случаев больше проходить ее не будет (дерется до конца)
