# Основная процедура
1 караул == 4 часа. В дне 6 караулов. **1-ый караул - всегда начало светлого времени суток**
- В начале дня кидается погода
	1. Игроки выбирают действие:
	2. Мастер считает прогресс движения, если он есть.
	3. Мастер проверяет навигацию, если есть риск.
	4. Мастер проверяет событие.
	5. Играем ситуации.
	6. Следующий караул.
- В конце дня списываются припасы

# Опасность территорий
От опасности территории зависит частота встреч, событий и т.п.
Об опасности территорий можно узнавать в игре

| Зона                                   | Шанс события за караул |
| -------------------------------------- | ---------------------: |
| Обжитая (спокойная)                    |                 1 из 6 |
| Дикая обычная (опасная)                |                 2 из 6 |
| Особо опасная / проклятая / враждебная |                 3 из 6 |
# Навигация
Навигация проверяется при **каждом** *активном* **карауле**.
- Движение, разведка, охота - вы можете забрести не туда

|Местность|Потеря направления|
|---|--:|
|Равнины / clear / grasslands|1 из 6|
|Пустоши, холмы, горы, лес|2 из 6|
|Пустыня, джунгли, болото|3 из 6|
