# **Охота**
Охота - это групповое действие, занимающее 2 хода
- Вы шумите и оставляете следы
- Хорошая добыча может привлечь внимание с риском 2 из 6
Плюсы и минусы к охоте не могут вывести результат за пределы 1-6

|  d6 | Результат охоты                       | Человеко-дни | Для партии из 5 |
| --: | ------------------------------------- | -----------: | --------------: |
|   1 | Ничего                                |            0 |          0 дней |
|   2 | Мелкая добыча: *1 слот* добытой еды   |            3 |         0.6 дня |
| 3–4 | Обычная добыча: *2 слота* добытой еды |            6 |         1.2 дня |
|   5 | Хорошая добыча: *3 слота* добытой еды |            9 |         1.8 дня |
|   6 | Большая добыча: *4 слота* добытой еды |           12 |         2.4 дня |

Во время охоты можно использовать Охотничьи ловушки

| Использование ловушек            | Эффект                                           |
| -------------------------------- | ------------------------------------------------ |
| Поставить ловушки во время охоты | +1 к броску охоты                                |
| Оставить ловушки на ночь         | утром бросок охоты с -1, но без траты 2 караулов |

| Размер группы  | Эффект                             |
| -------------- | ---------------------------------- |
| 1–2 охотника   | -1 к броску                        |
| 3–6 охотников  | без изменений                      |
| 7–10 охотников | +1 к броску, но +1 к риску встречи |

Добыча полученная на каких-нибудь болотах, проклятых землях. Или если вы пытаетесь съесть монстра -- может быть опасной: *болезнь, яд, проклятие, мутации, кошмары, паразиты и т.д.*

# **Фуражирование**

|  d6 | Результат            |
| --: | -------------------- |
| 1–3 | Ничего               |
| 4–5 | 1 порция добытой еды |
|   6 | 2 порции добытой еды |

| Местность                                                                 | Модификатор                                       |
| ------------------------------------------------------------------------- | ------------------------------------------------- |
| Богатая пищей: лес, река, болото с нормальной живностью, плодородные луга | +1                                                |
| Обычная дикая                                                             | без изменений                                     |
| Бедная: горы, пустошь, зима, сухие холмы                                  | -1                                                |
| Дорога / обжитая местность                                                | обычно нельзя или только если специально свернуть |
| Пустыня / мёртвая земля / проклятая земля                                 | нельзя или результат опасен                       |
