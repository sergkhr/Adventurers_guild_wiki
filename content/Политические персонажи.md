Не обязательные дополнительные (или основные, это как посмотреть) персонажи игроков, которые не ходят на вылазки, но и скорее всего не умирают в подворотне.

Персонажи для развития каких-то сюжетов, политической социалки и т.п.

У них минимально прописанных механик. И играются они по большей части заявками с мастером, часто даже в личке, может и между сессиями.
Играть в них я буду только с энтузиастами, потому что их надо использовать для историй, а не для игры в механики.

> Мое базовое предположение, что это что-то типа покровителей боевых персонажей, которые пытаются с помощью боевых персонажей добиться каких-то своих целей.

### Правила
Табличка учета персонажа. Кто он, что он, какие цели и т.д. можно просто записать в биографию.

| **Имя**              |                        |
| -------------------- | ---------------------- |
| **Роль / Положение** |                        |
| **Продвижение**      | 1 / N                  |
| **Достатки**         | Сторонники, Информация |
| **Нужды**            | Деньги                 |
| **Рычаги**           | 0                      |

**Достаток** — значимый ресурс, которого у персонажа сейчас больше необходимого и который можно потратить для решения подходящей проблемы.

**Нужда** — значимый ресурс, нехватка которого уже создаёт проблему.

При **3 Нуждах** возникает **Кризис**.
**Кризис** - это сюжетное "плохо" вам.

**Продвижение** происходит через создание и выполнение персональных целей, согласованных с мастером.

**Рычаг** можно получить, потратив ресурс
Рычаг позволяет совершить некое правдоподобное влияние: 
- Добавить полезную деталь, ресурс, контакт, подготовку или др. Боевым персонажам на вылазке.
- Подготовить запасного боевого персонажа (связанного с вашим политическим персонажем).
- Раздобыть какой-нибудь ресурс для боевого персонажа.
