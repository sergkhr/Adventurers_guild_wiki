# **Действия путешествия**
День поделен на отрезки по 4 часа - один "ход", "караул" и т.д.
За ход группа выбирает:
- Основное действие -- может быть только одно; основная деятельность
- Вторичные / модификаторы -- может быть сколько угодно, но без повторений
___
## *Основные действия*

| Основное действие | Что дает                                                                                                               | Требования                                             | Заметка                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| Переход           | Позволяет совершать прогресс путешествия.<br>*Дает 2 прогресса.*                                                       |                                                        | *Активный ход*                                                                            |
| Разведка          | Позволяет обнаружить случайные скрытые аспекты гекса.<br><br>Или найти что-то конкретное в гексе                       |                                                        | *Активный ход*                                                                            |
| Охота             | Позволяет получить припасы                                                                                             | Занимает 2 хода<br><br>Повышенные риски встречи        | *Активный ход*                                                                            |
| Отдых             | *Снимает 1 усталость*                                                                                                  | Занимает 4 хода<br><br>*Нужно быть в "Хорошем лагере"* |                                                                                           |
| Ставить лагерь    | Получить "Защиту" для лагеря                                                                                           | *Требования различаются от ситуации*                   | (подробнее в "усталости")                                                                 |
| Сон               | Длительный отдых в соответствии с системой                                                                             | Для эффекта нужно сделать 2 хода сна                   | без сна будет +усталость                                                                  |
| Общее действие    | Позволяет игрокам *по отдельности* выполнять разные небольшие дела<br><br>Например мелкий крафт, выпас животных и т.д. |                                                        | Обычно является спокойной активностью. Если только дело не какое-то особо требовательное. |
___
## *Дополнительные действия*

| Дополнительное действие                                       | Что дает                                                                                                    | Требования                                                                                                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Быстрый темп<br><br>Нельзя совмещать с "Разведкой" и "Охотой" | +1 прогресса при переходе<br><br>                                                                           | -1 на навигацию<br><br>Хуже положение при встречах                                                                                          |
| Осторожный темп                                               | +1 на навигацию<br><br>Лучше положение при встречах                                                         | -1 прогресса при переходе<br><br>-1 при разведке <br><br>-1 при охоте                                                                       |
| Фуражирование                                                 | Позволяет найти немного еды при переходе или разведке                                                       | -1 прогресса при переходе<br><br>-1 к целенаправленной разведке<br><br>шанс успеха общей разведки 4 из 6<br><br>Хуже положение при встречах |
| Картографирование                                             | Аккуратное добавление местности на вашу карту  === *При последующих действиях в этом гексе +1 на навигацию* | -1 прогресса при переходе<br><br>-1 к целенаправленной разведке<br><br>шанс успеха общей разведки 4 из 6                                    |
| Разведка по пути                                              | Позволяет совершать "Разведку", совершая "Переход"<br><br>                                                  | -1 прогресса при переходе<br><br>-1 к целенаправленной разведке<br><br>шанс успеха общей разведки 4 из 6                                    |
___
## *Активные действия (ограничения)*

| Номер активного хода после сна | эффект                                                                                                    |
| ------------------------------ | --------------------------------------------------------------------------------------------------------- |
| 1                              | норма                                                                                                     |
| 2                              | норма                                                                                                     |
| 3                              | *+1 усталость*<br>Если следующий сон будет в "хорошем лагере", то эта усталость снимается *дополнительно* |
| 4+                             | +1 усталость                                                                                              |
