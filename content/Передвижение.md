# **Прогресс движения**
Продвижение по клеткам требует "прогресса"
Действия, и разные баффы влияют на этот прогресс.

| Клетка            | Требование прогресса | Заметка |
| ----------------- | -------------------- | ------- |
| **Обычная**           | **2**                    |         |
| Трудная местность | 3                    | редко   |
| Очень трудная     | 4                    | редко   |

Примеры:
- Действие движения === дает 2 прогресса
	- Если кто-то перемещается ощутимо быстрее -- разберемся .. ну там по скоростям прикинуть можно
	- Если вы можете двигаться по прямой и не сверяться ни с чем (полет) - то *умножаем в 2 раза* (полет имба)
- Быстрый темп === +1 прогресс
- Дорога === +1 прогресс
