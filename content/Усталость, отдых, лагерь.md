## *Усталость*
Эффекты усталости кумулятивны

| Уровень        | Эффекты                                                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1 (Утомлены)   | "Быстрый темп" создает риск усталости 2 из 6                                                                            |
| 2 (Измотаны)   | -1 на навигацию и разведку <br><br>хуже положение при встречах                                                          |
| 3 (На пределе) | Любой "активный" ход создает риск усталости 2 из 6<br><br>"Быстрый темп" дает +1 усталости (риск до 6 из 6 поднимается) |
| 4 (Срыв)       | -2 "прогресса" при переходе<br><br>-2 к разведке<br><br>-2 к охоте                                                      |
| 5+             | Последствия в боевке = помехи и прочее дерьмо вплоть до травм                                                           |
### Как снимать

| Отдых                   | Эффект       |
| ----------------------- | ------------ |
| Действие отдых          | -1 усталость |
| Сон в "Хорошем лагере"  | -1 усталость |
| *Safe rest не в городе* | -1 усталость |
| Safe rest в городе      | -2 усталости |
### Как получать
Много чего может вызвать усталость. Получение усталости указывается там где она дается. Но вот здесь несколько примеров дополнительных ситуаций.
- Много активничали
- Не поели 
- Тяжелая погода может давать усталость
- Не спали

## *Хороший лагерь*
Вы можете просто остановиться ночевать - вы разобьете лагерь. Но это будет без хорошего укрытия и все броски будут обычными... Может быть погода будет ощущаться менее приятно.

Но можно подготовить к отдыху "Хороший лагерь"
*"Хороший лагерь" дает:*
- Вероятность энкаунтера -1
- Сон снимает 1 усталость
- Укрытие, удобная положение и т.д. -- все это не забываем если вдруг что-то произойдет

*"Хороший лагерь" требует:*
- есть укрытие;  
- есть еда и вода;  
- есть тепло/сухость;  
- выставлена стража;  
- лагерь не на очевидно опасном месте.
### Получение хорошего лагеря

| Условия / Окружение                         | Требования для лагеря                                           |
| ------------------------------------------- | --------------------------------------------------------------- |
| Нашли подходящее место                      | Бесплатно                                                       |
| лес, холмы, равнины                         | 1 ход                                                           |
| болото, горы, руины, вражеская зона         | *1 ход*<br>*+ нужна проверка*: базово 3 из 6 дальше по ситуации |
| пустыня, проклятая земля, демоническая зона | Без особых ресурсов может быть невозможно                       |
