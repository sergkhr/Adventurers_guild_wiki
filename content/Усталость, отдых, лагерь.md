## *Усталость*
Эффекты усталости кумулятивны

| Уровень        | Эффекты                                             |
| -------------- | --------------------------------------------------- |
| 1 (Утомлены)   | "Активный ход" дает Риск усталости +1 из 6          |
| 2 (Измотаны)   | Риск потеряться +1 из 6<br><br>Риск встречи +1 из 6 |
| 3 (На пределе) | Противники всегда ходят первыми                     |
| 4 (Срыв)       | -1 эффективности всех действий                      |
| 5+             | Помехи / минус действия / раны и т.п.               |
### Как снимать

| Способ                               | Эффект       |
| ------------------------------------ | ------------ |
| Действие отдых                       | -1 усталость |
| "Двойные пайки" (см. хороший лагерь) | -1 усталость |
| *Safe rest не в городе*              | -1 усталость |
| Safe rest в городе                   | -2 усталости |
### Как получать
Усталость может вызвать очень много всего. Также есть постоянные моменты:
- Не поели - в конце 6-го караула, каждый должен потратить паек. Иначе +1 усталость.
- Не поспали - за день (6 караулов), группа должна поспать 2 караула, иначе, в конце дня +1 усталость.

В правилах есть места где указано, что дает усталость. Но вот общая сводка
- Риск за активный ход
- Риск от погоды

## *Хороший лагерь*
Вы можете просто остановиться ночевать - вы разобьете лагерь. Но это будет без хорошего укрытия и все броски будут обычными... Может быть погода будет ощущаться менее приятно.

Но можно подготовить к отдыху "Хороший лагерь"
*"Хороший лагерь" дает:*
- Вероятность энкаунтера -1 -- *нужно иметь защиту в лагере*
- Сон в хорошем лагере позволяет выполнить Night's rest 
- Возможность - "Двойные пайки" -- если вы завершаете день в "хорошем лагере", то вы можете 1 раз дополнительно поесть (1 паек каждому), это снимает 1 усталость.
- Укрытие, удобная положение и т.д. -- все это не забываем если вдруг что-то произойдет

*"Хороший лагерь" требует:*
Закрытия всех аспектов. Угроза защите есть всегда, остальные угрозы возникают по ситуации:
- Защита - *всегда требуется*
- Влага
- Едкий туман
- Холод
- Холод++
- Жара
- Жара++

### Обустройство лагеря
Действие постановка лагеря - позволяет "добавить" защиту от одной из угроз.
> простите тавтологию
- Добавить "защиту" вы можете всегда
- Для остального вам скорее всего понадобятся особые материалы

**На трудной для аспекта местности**, появляется риск не успеть выполнить обустройство.

| Условия / Окружение                         | Требования для лагеря                                           |
| ------------------------------------------- | --------------------------------------------------------------- |
| Нашли хорошее место                         | Бесплатно, сразу                                                |
| лес, холмы, равнины                         | просто ход                                                      |
| болото, горы, руины, вражеская зона         | *1 ход*<br>*+ нужна проверка*: базово 4 из 6 дальше по ситуации |
| пустыня, проклятая земля, демоническая зона | Без особых ресурсов может быть невозможно                       |
