# **Паверскейлинг**

| Уровни | Воспринимаются          | Кто это в мире                                             |
| ------ | ----------------------- | ---------------------------------------------------------- |
| 1–3    | обычные, но уже опасные | искатели-новички, бандиты, солдаты, молодые чудовища       |
| 4–6    | профессионалы           | ветераны, рыцари, шаманы, маги, лидеры малых логов         |
| 7–10   | герои                   | знаменитые искатели, чемпионы, чудовища из слухов          |
| 11–12  | человеческий предел     | легендарные мастера, почти невозможные люди                |
| 13+    | уже не люди             | святые, проклятые, демонизированные, драконьи, деусоносные |
